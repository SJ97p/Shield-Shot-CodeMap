# Shield & Shot Code Map

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트 | Shield & Shot |
| 장르 | 모바일 하이퍼캐주얼 디펜스 슈팅 |
| 기간 | 2026.06.04 ~ 2026.07.08 (데모 기준) |
| 인원 | 6인 팀 프로젝트 |

| 엔진 / 언어 | Unity 6.3.6f1 / C# |
| 핵심 기술 | Photon Fusion, Unity Input System, ScriptableObject, URP, VFX Graph |
